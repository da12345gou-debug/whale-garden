# 鲸游花园

橙色天空下，和女孩、白猫一起散步、观光、采集，再回原木小屋储藏和做饭的 3D 网页游戏。

此仓库保存可直接发布的网页版，包含百倍巨鲸、四种地貌、植物采集和小屋室内场景。

## 游玩

使用支持 WebGL 的电脑浏览器。首次打开需要加载模型；无需安装桌面程序。

- 点击地面：走到指定位置；长按左键：持续散步。
- WASD / 方向键：移动；界面可选择步行速度。
- 中键或右键拖动：调整视角；滚轮缩放。
- Page Up / Page Down：俯瞰、仰视；Home：恢复平视。
- 点击发光植物或靠近后按 E：采集。
- 家门口按 E：进屋；采集物进门时自动存入收藏柜，厨房可制作食物。
- B：手记；M：地图；P：拍照；Q：摸猫。

## 自动保存

进度保存在当前设备、当前浏览器和当前网站地址下。刷新或下次打开同一网址会继续生活。
不需要账号，没有云端存档。请不要使用无痕模式或清除网站数据。
不同设备、浏览器或网址之间不会自动同步；旧网站的存档不会自动迁移到 GitHub Pages。

## 发布

网站文件在 `public/`，可直接部署到静态托管，保留全部相对路径。
GitHub 仓库的 Settings → Pages 中选择 GitHub Actions 作为发布来源。
推送到 main 后，`.github/workflows/pages.yml` 会校验并发布网站。
最终游玩地址以 GitHub Pages 实际部署返回的 URL 为准。

本地校验：`node verify-pages.mjs`（Node.js 20 或以上）。
本地预览可使用任意静态 HTTP 服务器提供 `public/`；不要直接以 file:// 打开 HTML。
